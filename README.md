# Telegram Startup Analyst Bot

An AI-powered Telegram bot built with Python and the Google Gemini API to analyze startup ideas, business opportunities, and problems.

## What it does

The bot brings AI-powered startup analysis directly into Telegram.

It can be used to:
- Analyze startup ideas
- Explore business opportunities
- Identify potential problems worth solving
- Generate AI-powered insights
- Interact with an AI agent through Telegram

## Tech Stack

- Python
- Telegram Bot API
- Google Gemini API
- REST APIs

## Key Features

- Telegram-based AI interaction
- Gemini-powered analysis
- Automated responses
- Startup and opportunity analysis
- Environment-based API configuration
