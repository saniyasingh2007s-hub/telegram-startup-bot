# Telegram Startup Analyst Bot

An AI-powered Telegram bot that helps analyze startup ideas, opportunities, and business problems using the Google Gemini API.

## What it does

The bot provides AI-powered startup analysis directly through Telegram.

It was built to experiment with:
- AI-powered opportunity analysis
- Startup idea evaluation
- Automated Telegram interactions
- API-based AI workflows
- Continuous bot operation

## Tech Stack

- Python
- Telegram Bot API
- Google Gemini API
- REST APIs

## Key Features

- Telegram-based AI interaction
- Gemini-powered analysis
- Automated responses
- Startup and opportunity analysis
- Designed for continuous operation
